# BotMAX 🎰 — Бот и Мини-Приложение для мессенджера MAX

Полнофункциональный бот и современное мини-приложение для проведения розыгрышей призов в мессенджере **MAX** с приемом платежей через **СБП (Систему быстрых платежей)** и механикой **убытия лотерейных билетов в реальном времени**.

---

## 🌟 Основные возможности

### 1. Бот для мессенджера MAX (`maxapi` 1.2.2)
- Авторизация через официальный Bot API платформы MAX (`platform-api2.max.ru`).
- Настроен безопасный SSL-коннектор для работы с сертификатами Минцифры РФ (Russian Trusted Root CA).
- Команды:
  - `/start` — приветствие, кнопки запуска мини-приложения и навигации.
  - `/lottery` (или `/raffles`) — список актуальных призов со шкалой прогресса сборов и остатком билетов.
  - `/tickets` (или `/my_tickets`) — портфолио купленных билетов пользователя.
  - `/help` — подробная справка по механике лотереи и оплате по СБП.
  - `/admin` и `/draw <raffle_id>` — панель управления и подведение итогов розыгрыша.
- Кнопки:
  - `OpenAppButton` — запуск встроенного мини-приложения прямо внутри мессенджера MAX.
  - `LinkButton` — переход к веб-версии для браузеров.
  - `CallbackButton` — интерактивные ответы и карточки внутри чата.
- **Push-уведомления:**
  - При поступлении оплаты по СБП бот мгновенно отправляет пользователю квитанцию с номерами выкупленных билетов.
  - При завершении розыгрыша бот поздравляет победителя и публикует результаты.

### 2. Мини-Приложение (Mini-App Web)
- Разработано в соответствии с дизайн-системой **MAX UI** (светлая и темная темы, скругления squircle, микроанимации, адаптивность под мобильные устройства).
- **Каталог призов:**
  - Карточки с фото, описанием, стоимостью билета (в ₽), процентом сборов и количеством оставшихся билетов.
- **Интерактивное табло билетов (Drawdown / Убытие):**
  - Визуальная сетка всех номеров билетов от 1 до N.
  - Цветовая индикация статусов:
    - 🟢 **Доступен** — свободен для покупки.
    - 🟡 **Выбран вами** — в текущей корзине.
    - 🟡 **Бронь** — другой пользователь перешел к оплате по СБП.
    - 🔴 **Убыл (куплен)** — оплачен, зачеркнут и навсегда исключен из пула.
    - 🏆 **Победитель** — выигрышный билет с анимацией.
  - Быстрый выбор: «🎲 Случайный (Мне повезет!)», «+1 билет», «+3 билета», «+5 билетов».
  - Плавающая панель оформления заказа с подсчетом суммы в ₽.

### 3. Интеграция с СБП (Система быстрых платежей)
- Соответствие стандартам НСПК:
  - Генерация уникального `QRID`.
  - Динамическая платежная ссылка НСПК (`https://qr.nspk.ru/...`).
  - Мобильный диплинк (`sbp://qr.nspk.ru/...`) для вызова приложений банков (Сбер, Т-Банк, ВТБ, Альфа-Банк).
  - Генерация высококонтрастного динамического QR-кода с фирменным стилем СБП.
- Таймер удержания брони: билеты резервируются на 10 минут. Если оплата не завершена, фоновый процесс возвращает их в общий пул.
- Мгновенная проверка статуса и тестовая симуляция: кнопка «⚡ Симуляция успешной оплаты (Тест СБП)» для демонстрации и проверки без реального списания денег.
- Обработчик банковских вебхуков (`POST /api/payments/sbp/webhook`).

### 4. Честный розыгрыш (Provably Fair Draw)
- Использование криптографически стойкого генератора случайных чисел (`secrets.choice`) среди всех выкупленных билетов.
- Анимированная рулетка в мини-приложении и праздничные эффекты (конфетти).

## 🚀 Быстрый старт (Локальный запуск)

### 1. Требования
- Python 3.10+ (протестировано на Python 3.14)
- Доступ к интернету для связи с платформой MAX

### 2. Установка зависимостей
```powershell
cd c:\Users\user1\IdeaProjects\botmax\botmax
python -m venv venv
.\venv\Scripts\pip install -r requirements.txt
```

### 3. Настройка переменных окружения (`.env`)
Файл `.env` уже преднастроен:
```ini
MAX_BOT_TOKEN=f9LHodD0cOKlYORWpPyGoAg9P6wH1JzZeVVPSHl9Jdp4Qd6DwP8vFxU5Kvn12g6D1_7fG0VQCzkl-PRPN_kG
WEBHOOK_URL=https://anussai.duckdns.org/webhook
MINI_APP_URL=http://localhost:8000
SBP_MERCHANT_ID=test_merchant
HOST=0.0.0.0
PORT=8000
RUN_MODE=polling
```

### 4. Запуск приложения
```powershell
.\venv\Scripts\python.exe main.py
```
При запуске:
1. Создается база данных SQLite (`./data/botmax.db`) в режиме высокой производительности WAL.
2. Автоматически заполняются 4 стартовых розыгрыша призов (iPhone 16 Pro Max, PS5 Slim, AirPods Max, Ozon).
3. Запускается фоновый обработчик авто-освобождения просроченных броней билетов.
4. Запускается бот MAX в режиме Long Polling.
5. На `http://localhost:8000/` открывается веб-сервер с мини-приложением и REST API.

## 🌐 Проверка в браузере и мессенджере

- **Мини-приложение в браузере:** перейдите по адресу [http://localhost:8000/](http://localhost:8000/)
- **API эндпоинты:**
  - `GET /health` — проверка работоспособности.
  - `GET /api/raffles` — список всех розыгрышей и статус убытия.
  - `GET /api/raffles/{id}` — состояние всех билетов розыгрыша.
  - `POST /api/raffles/{id}/reserve` — бронирование билетов и генерация СБП.
  - `POST /api/orders/{order_id}/confirm-simulation` — тестовая оплата СБП.
  - `POST /api/payments/sbp/webhook` — банковский вебхук СБП.
