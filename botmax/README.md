# BotMAX - Бот для розыгрышей в MAX мессенджере

Бот для проведения розыгрышей лотерейных билетов с оплатой через СБП в группе MAX мессенджера.

## 📋 Описание

BotMAX позволяет:
- Создавать розыгрыши с настраиваемым количеством билетов и ценой
- Принимать оплату через СБП с использованием мини-приложений
- Автоматически убирать проданные билеты с продажи
- Проводить случайный выбор победителей
- Уведомлять участников о результатах

## 🛠️ Технические детали

- **Язык**: Python 3.8+
- **Библиотека бота**: [max-botapi-python-main](https://github.com/max-messenger/max-botapi-python) (официальная библиотека MAX)
- **База данных**: SQLite с aiosqlite для асинхронной работы
- **Логирование**: Стандартный logging с ротацией файлов
- **Архитектура**: Модульная с разделением ответственности

## ⚙️ Установка и настройка

### 1. Клонирование репозитория
```bash
git clone <repository-url>
cd botmax
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Настройка окружения
Скопируйте пример конфигурации и заполните необходимые значения:
```bash
cp .env.example .env
# Отредактируйте .env файл, добавив:
# MAX_BOT_TOKEN=ваш_токен_бота
# WEBHOOK_URL=https://ваш_домен.com/webhook
# MINI_APP_URL=https://ваш_миниприложение.com
# SBP_MERCHANT_ID=ваш_идентификатор_торговца
```

### 4. Создание необходимых директорий
```bash
mkdir -p data logs
```

## 🚀 Запуск

### Для тестирования (режим polling):
```bash
python main.py
```
*Режим polling подходит для разработки и тестирования. Не используйте в production без HTTPS вебхука.*

### Для production (режим webhook):
```bash
# Убедитесь, что у вас настроен HTTPS сервер на порту 443
# Затем запустите:
python main.py
# В клиенте бота нужно будет изменить метод запуска на start_webhook
```

## 🧪 Тестирование

### Тестовый сценарий:
1. Запустите бота: `python main.py`
2. Добавьте бота в тестовый чат и сделайте администратором
3. Используйте команду `/help` для получения списка команд
4. Создайте тестовый розыгрыш: `/lottery create "Тестовый розыгрыш" 10 50`
5. Бот отправит сообщение с кнопками для покупки билетов
6. Нажмите на кнопку покупки - бот симулирует успешную оплату
7. После продажи всех билетов используйте `/lottery finish <id>` для выбора победителя
8. Бот объявит победителя и завершит розыгрыш

### Тестирование оплаты:
Для полной проверки оплаты по СБП необходимо:
1. Настроить настоящее мини-приложение для СБП платежей
2. Указать правильные URL в конфигурации
3. Интегрировать с реальным платежным шлюзом

## 📝 Требования к окружению

- Python 3.8 или выше
- Доступ к интернету для связи с API MAX
- Для production: HTTPS сервер с доверенным сертификатом (порт 443)
- Токен бота от платформы MAX (только для юрлиц/ИП/самозанятых РФ)

## 🔒 Безопасность

- Токен бота хранится в переменных окружения (не в коде)
- Все данные хранятся локально в SQLite базе
- Рекомендуется регулярно делать резервные копии базы данных
- Для production используйте вебхуки вместо long polling
